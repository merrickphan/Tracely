## What did change

**The cardiology failure is gone.** The baseline's most-cited example — three
American-cardiology guidelines retrieved for the AAP school-start claim because
they matched "American … Association/College" — does not recur. That claim now
returns 1 rel / 3 marg / 4 irr, the same ratio as before, with the four
irrelevant slots refilled by unrelated historical-education papers. The named
bug was fixed; the number it was blamed for did not move.

## Three findings worth acting on

**1. A duplicate source shipped to the same claim.** 02-remote-work C1 returns
"Is Hybrid the Future of Work: Evidence from A CHINESE EXPERIMENT" twice. The
two titles differ only by an embedded newline, so the dedupe fallback in
`aggregator.ts` (normalized title + year, used when there is no DOI) treated
them as different papers. Whatever that normalizer does, it does not collapse
internal whitespace.

**2. The eval structurally cannot see the World Bank provider.** It contributed
0 of 104 sources, and not only because the essays are short on statistical
claims. `src/main/eval/timing.ts` warms `services/ml` but never calls
`worldBank.warmUp()`, and `worldBank.search()` returns `[]` immediately while
its index is cold, kicking off a build the run never waits for. With 13 claims
and no second pass, that provider can never appear in a report regardless of
how well it works. Eval coverage for it starts by warming it in the harness.

**3. Three claims spend 24 source slots on the unanswerable.** 01-C4 ("sleep
debt is the *primary driver*… more than smartphones"), 01-C5 ("depression rates
will double within the next decade") and 02-C3 (remote workers less likely to
be promoted) return 0 rel between them. The first two are a causal-primacy
claim and an unfalsifiable prediction; no literature can support either as
phrased. `worldBank.ts` already implements the principle that would help here —
silence beats a plausible-looking wrong answer — but only that one provider
abstains.

## Update — findings 1 and 2 are fixed

On branch `fix/eval-findings`. Both were verified by a free cassette replay
(`report-2026-08-10T00-16-56-169Z`, 0 paid relay calls).

**The duplicate is gone**, and the cause was not the one written above. Both
records carried DOIs (`10.1257/rct.8075-1.0` and `-1.1`), so it was always the
title fallback's job to merge them, and it failed because the two providers
disagreed about where a word boundary was: `fromA` normalized to `froma`,
`from\nA` to `from a`. Mapping separators to a space preserves that; dropping
them removes it. The freed slot refilled with *Working Remotely? Selection,
Treatment, and the Market for Remote Work* — a better source than the copy it
replaced, so this claim's precision improved slightly. The strict count above
is not restated, because it would need relabelling to be honest.

**The harness now warms World Bank** and waits for `isReady()` before the first
claim. It still contributes 0 of 104 sources — but that is now measured
silence, not a cold index: none of these 13 claims is answerable by a World
Development Indicator, exactly as `probe-statistical.mjs` predicted. Real
coverage needs an essay with an answerable statistical claim.

**Finding 3 is measurable but not worth much.** Only one of the three
zero-relevance claims is separable by a signal the pipeline already has —
01-C5 is typed `prediction`. The other two are `causal`, the same type as
01-C3, which is the *best*-retrieving claim in the whole set (7 rel of 8).
Abstaining on predictions alone moves strict precision from 23/104 (22%) to
23/96 (24%). Abstaining on all three, if they could be told apart, gives 23/80
(29%) — back to the baseline and no better. **Abstention tidies the evidence
list; it does not fix retrieval**, and it costs a UX decision (what a claim
card shows when the app declines to look) for two points. Worth doing for
honesty, not for the number.

## The lexical noise is unchanged in character

Every failure mode the baseline named is still present, matching on the wrong
sense of a word:

- "visibility" → *Lancet Global Health Commission on Global Eye Health: vision
  beyond 2020*, for a claim about being visible to your manager
- "existed … before" → *DNA could have existed long before life itself*, for
  movable type predating Gutenberg
- "next decade" → *Need for home economics teachers in Iowa's public schools
  for the next decade*, for teen depression rates
- "merchant" + "paper" + "character" → *The Merchant as Character on Paper*,
  for the alphabet's small character set
- "remote" → *Remote Agent: to boldly go where no AI system has gone before*
